# COMPOUND.OS Windows 桌面版使用说明

> 本文件随 `dist/COMPOUND.OS.zip` 一起交付。

## 1. 这是什么

COMPOUND.OS 桌面版 = 同一个单文件网页工作台 + PyWebView 本地窗口壳。

- 外观、交互与网页版完全一致；
- 双击 `COMPOUND.OS.exe` 即可打开，不依赖浏览器标签页；
- 所有数据保存在本机 `%LOCALAPPDATA%\CompoundOS`，换电脑时复制该文件夹即可迁移；
- 资讯外链自动交给系统默认浏览器打开；
- 程序为绿色便携版，解压即可用，无需安装。

## 3. 桌面快捷方式

如果你看到压缩包里或桌面上已有 `COMPOUND.OS.lnk`，直接双击即可。快捷方式目标指向解压目录的 `COMPOUND.OS.exe`。

若快捷方式丢失或想重新创建：

1. 右键 `COMPOUND.OS.exe` →「发送到」→「桌面快捷方式」；
2. 右键刚创建的快捷方式 →「属性」→「更改图标」→ 选择 `_internal\assets\rose.ico`。

## 4. 数据位置与迁移

| 文件   | 路径                                         | 说明                 |
| ---- | ------------------------------------------ | ------------------ |
| 主状态  | `%LOCALAPPDATA%\CompoundOS\workspace.json` | 待办、增长曲线、健康、爱意等全部数据 |
| 资讯缓存 | `%LOCALAPPDATA%\CompoundOS\news.json`      | AI 能力雷达的本地缓存       |
| 调试日志 | `%LOCALAPPDATA%\CompoundOS\app.log`        | 桌面版运行日志（如有异常可先查看）  |

### 迁移到新电脑

1. 在新电脑上首次运行并关闭 COMPOUND.OS（生成数据目录）；
2. 把旧电脑的 `CompoundOS` 文件夹复制到新电脑同名位置，覆盖即可。

### 从网页版迁移到桌面版

1. 在网页版右下角「设置」→「导出 JSON 备份」；
2. 在桌面版同样位置「导入 JSON 备份」；
3. 导入后数据会立即写入 `%LOCALAPPDATA%\CompoundOS\workspace.json`。

## 6. 常见问题

**Q：双击没反应或一闪而过？**  
A：确认已完整解压整个文件夹；确认系统已安装 Microsoft Edge WebView2 Runtime（Windows 11 通常已自带，Windows 10 部分旧版本需手动安装）。

**Q：想换一台电脑使用？**  
A：复制整个解压文件夹，并复制 `%LOCALAPPDATA%\CompoundOS` 数据目录。

**Q：数据会丢失吗？**  
A：数据保存在本地磁盘，正常不会丢失。建议定期在设置里「导出 JSON 备份」。

**Q：可以删除 `_internal` 目录吗？**  
A：不可以。`_internal` 包含程序依赖和网页资源，删除后程序无法运行。

**Q：如何彻底卸载？**  
A：删除解压文件夹 + 删除 `%LOCALAPPDATA%\CompoundOS` 数据目录即可。

## 7. 技术信息

- 打包方式：PyInstaller 6.x `--onedir --windowed`
- 窗口引擎：PyWebView + Microsoft Edge WebView2
- 状态持久化：Python 原子写入 JSON（先写临时文件再替换）
- 图标：金色玫瑰 `assets/rose.ico`
